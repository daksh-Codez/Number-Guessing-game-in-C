# 🎮 Number Guessing Game in C

A console-based **Number Guessing Game** developed using the C programming language. This project challenges players to guess a randomly generated number within a limited number of attempts based on the selected difficulty level.

## 📌 Overview

The Number Guessing Game is an interactive terminal-based application where the computer generates a random number and the player has to guess it.

The game provides multiple difficulty levels, each with a different number range and attempt limit, making the experience more challenging and engaging.

## ✨ Features

- **Random Number Generation:** Generates a random number for every game.
- **Multiple Difficulty Levels:** Choose between Easy, Medium, and Hard modes.
- **Limited Attempts:** Each difficulty level has a specific attempt limit.
- **Instant Feedback:** Get hints whether your guess is too high or too low.
- **Win/Lose Conditions:** Displays the result based on your performance.
- **Interactive Interface:** Simple and user-friendly terminal experience.

## 🎯 Difficulty Levels

| Difficulty | Number Range | Attempts |
|---|---:|---:|
| Easy | 1–50 | 10 |
| Medium | 1–100 | 7 |
| Hard | As configured in the program | As configured in the program |

## 🛠️ Technologies Used

- C Programming Language
- Standard Input/Output (`stdio.h`)
- Random Number Generation (`stdlib.h`)
- Time Library (`time.h`)
